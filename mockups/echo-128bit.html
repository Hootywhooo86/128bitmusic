WHAT CHANGED

  • Pixelated covers

    Each cover is downsampled to 32×32, dithered, and scaled up with no smoothing. Also used as the player background. New option PlayerBackgroundStyle.PIXEL.

  • Square corners, hard shadows, no glass

    Every shape goes to 0dp, shadows become solid offsets, and Liquid Glass is off in pixel mode. A pixelMode branch in Theme.kt.

  • Block seek bar

    32 cells that fill one at a time. New SliderStyle.BLOCKS next to Wavy and Slim.

  • Arcade lyrics

    The active line is set in a pixel font and words light up in steps, using Echo's existing word timing. New LyricsAnimationStyle.ARCADE.

  • XP, levels, streaks

    Computed from the plays Echo already logs (Event: song, time, play length). No new tracking and no database migration.

  • Stats as a save file

    Your level and class, top tracks as an inventory, badges and weekly quests. A pixel layout for StatsScreen.kt.
