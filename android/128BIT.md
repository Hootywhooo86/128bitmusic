# 128bit Music (Android)

128bit Music is a modified version of [Echo Music](https://github.com/EchoMusicApp/Echo-Music)
with a pixel-art look. Everything Echo does still works the same way: YouTube Music sign-in,
streaming, downloads, playlists, synced lyrics, Echo Find, Listen Together and Spotify import.
The changes are only to how it looks.

- **Upstream:** Echo Music @ `399e6bcb44ebd2d3e08915d13f079b7af3ee1635` (2026-10-04)
- **License:** GPL-3.0, same as Echo (see [`LICENSE`](LICENSE)). Any build you share must stay
  open source under GPL-3.0.
- **App ID:** `com.bit128.music` (`com.bit128.music.debug` for debug builds), so it installs
  next to Echo instead of replacing it.

## Build it

You need JDK 21 and the Android SDK (platform 37).

```bash
cd android
echo "sdk.dir=/path/to/android/sdk" > local.properties
./gradlew :app:assembleUniversalFossDebug -x lint
# APK: app/build/outputs/apk/universalFoss/debug/
```

### Getting the APK on your phone

Every successful build that touches `android/` is published as a numbered release:
**128bitmusicv001.apk**, then v002, v003, ... (one higher each time; a failed build doesn't use
up a number). The app shows the same number in Settings → About.

- All versions: https://github.com/Hootywhooo86/128bitmusic/releases
- Always the newest one (fixed link):
  **https://github.com/Hootywhooo86/128bitmusic/releases/download/app-latest/128bit-music.apk**

Open either on your phone and tap the download to install. Every build is signed with the same
key and has a higher version code, so it installs as an update over the last one and keeps your
sign-in, library and downloads.

### Signing key (one-time setup)

Release builds are signed with the key stored in the `RELEASE_KEYSTORE_BASE64` repo secret
(Settings → Secrets and variables → Actions). The key never goes in the repo. Keep a backup of
the `.jks` file: if the key is lost, the next build can't update the installed app, and you'll
have to uninstall and reinstall. Until the secret is set, CI only builds a debug APK and
attaches it to the run as an artifact.

### Moving over from Echo

1. In **Echo**: Settings → Backup and restore → **Backup**. Save the file.
2. Install 128bit Music, then go to Settings → Backup and restore → **Restore** and pick that file.
   This brings over settings (usually including your YouTube sign-in), playlists, liked songs
   and history.
3. Downloaded songs are files inside Echo's own storage and aren't part of the backup. Download
   them again in 128bit Music before you uninstall Echo.
4. If the restore brings back a font, seek bar or player background you picked in Echo, switch
   them back under Settings → Appearance.

## Pulling in Echo updates

Echo is under active development. To pick up their fixes, diff upstream against the commit
above and apply the changes into `android/`. Most of our edits are contained in new files
(`PixelTheme.kt`, `PixelPalettePicker.kt`, `PixelBlockTrack.kt`, `PixelCoverBackground.kt`).
The corner change touches many files, but you can redo it on fresh upstream code: swap
`RoundedCornerShape` for `PixelCornerShape` and `CircleShape` for `PixelCircleShape`, outside
import lines.
