# 128bit Music (Android)

128bit Music is a modified version of [Echo Music](https://github.com/EchoMusicApp/Echo-Music)
with a pixel-art look. Everything Echo does still works the same way: YouTube Music sign-in,
streaming, downloads, playlists, synced lyrics, Echo Find, Listen Together and Spotify import.
The changes are only to how it looks.

- **Upstream:** Echo Music @ `399e6bcb44ebd2d3e08915d13f079b7af3ee1635` (2026-10-04)
- **License:** GPL-3.0, same as Echo (see [`LICENSE`](LICENSE)). Any build you share must stay
  open source under GPL-3.0.
- **App ID:** `com.bit128.music` (`com.bit128.music.debug` for debug builds), so it installs
  next to Echo instead of replacing it.

## What's different from Echo

Changes made 2026-10-05:

| Area | Change | Files |
|---|---|---|
| Colors | 11 palettes (128BIT, CARTRIDGE, DOT MATRIX, POCKET, VAPORWAVE, AMBER CRT, RED SCREEN, PICO, CONSOLE, ARCTIC, ECHO COLORS), picked under **Settings → Appearance → Theme**. CARTRIDGE takes its accent from the current cover art. ECHO COLORS restores Echo's original Material You colors. | `ui/theme/PixelTheme.kt`, `ui/component/PixelPalettePicker.kt`, `ui/theme/Theme.kt`, `ui/screens/settings/ThemeScreen.kt`, `MainActivity.kt` |
| Corners | Every rounded corner and circle in the app is drawn as pixel stair-steps (`PixelCornerShape`, `PixelCircleShape`) instead of smooth curves. | `ui/theme/PixelTheme.kt` + call sites across `app/src` |
| Fonts | New default font "128bit Pixel": Press Start 2P for large titles, Pixelify Sans for everything else. Echo's other fonts are still available. | `ui/theme/PixelTheme.kt`, `ui/theme/Theme.kt`, `ui/screens/settings/FontSelectionScreen.kt`, `res/font/` |
| Seek bar | New "Blocks" seek bar (row of square cells), now the default. | `ui/component/PixelBlockTrack.kt`, `ui/player/Player.kt`, `ui/screens/settings/AppearanceSettings.kt` |
| Player background | New "Pixel" background: the cover art turned into big chunky pixels with scanlines. It's now the default. The main album art stays sharp. | `ui/component/PixelCoverBackground.kt`, `ui/player/Player.kt`, `ui/player/MiniPlayer.kt` |
| Glass | Liquid Glass blur is turned off; those surfaces use Echo's solid fallback. | `ui/component/GlassEffect.kt` |
| Identity | App name "128bit Music", pixel Discman launcher icon, new app ID. Echo's Firebase config is removed so no analytics go to Echo's project. Echo's startup update check defaults to off, because it points at Echo's releases. | `app/build.gradle.kts`, `res/values/app_name.xml`, `res/mipmap-anydpi-v26/`, `res/drawable/ic_128bit_*`, `echomusic/updater/echomusicupdater.kt` |

Fonts: Press Start 2P and Pixelify Sans are licensed under the SIL Open Font License; see
[`fonts-licenses/`](fonts-licenses).

## Build it

You need JDK 21 and the Android SDK (platform 37).

```bash
cd android
echo "sdk.dir=/path/to/android/sdk" > local.properties
./gradlew :app:assembleUniversalFossDebug -x lint
# APK: app/build/outputs/apk/universalFoss/debug/
```

GitHub Actions also builds this APK on every push that touches `android/`. Open the
**Actions** tab, click the latest "Build 128bit Music APK" run, and download the
`128bit-music-debug-apk` artifact.

**Signing:** each Actions run signs with a new throwaway debug key, so you'd have to uninstall
before installing a newer build (and lose your downloads and sign-in). To fix that, create one
keystore and save it as a repo secret named `DEBUG_KEYSTORE_BASE64`:

```bash
keytool -genkeypair -v -keystore debug.keystore -storepass android -alias androiddebugkey \
  -keypass android -keyalg RSA -keysize 2048 -validity 10000 -dname "CN=128bit Debug"
base64 -w0 debug.keystore   # paste the output into the secret
```

## Pulling in Echo updates

Echo is under active development. To pick up their fixes, diff upstream against the commit
above and apply the changes into `android/`. Most of our edits are contained in new files
(`PixelTheme.kt`, `PixelPalettePicker.kt`, `PixelBlockTrack.kt`, `PixelCoverBackground.kt`).
The corner change touches many files, but you can redo it on fresh upstream code: swap
`RoundedCornerShape` for `PixelCornerShape` and `CircleShape` for `PixelCircleShape`, outside
import lines.
